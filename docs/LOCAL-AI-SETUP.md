# 로컬 AI 실행 실험

## 실행 환경

- Android SDK Platform 35, JDK 17 이상
- Kotlin 2.4.0, Android Gradle Plugin 8.13.2, LiteRT-LM 0.18.0 (버전 고정)
- 실험 APK는 arm64-v8a만 지원. GPU 실행 가능 여부는 기기에서 확인 필요
- 모델: `litert-community/gemma-4-E2B-it-litert-lm`의 `gemma-4-E2B-it-gpu.litertlm`
- 파일 크기: 2,008,432,640바이트 (약 2GB). 다운로드 파일과 앱 내부 복사본을 함께 보관하면 약 4GB 필요
- SHA-256: `a53a59001894c58e6bdb5b9b227709f91a2e3e556baa7d85acf9c55402ba5cf5`

공식 배포 페이지: https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm

## 빌드와 설치

```powershell
cd android
.\gradlew.bat assembleDebug --console=plain
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 모델 준비와 실행

1. 공식 배포 페이지에서 GPU용 모델을 내려받는다.
2. 파일을 휴대폰 Download 폴더로 복사한다.
3. 앱에서 `로컬 AI 답변 테스트` → `모델 파일 선택`으로 파일을 선택한다.
4. 복사가 끝나면 `모델 불러오기`를 누른다.
5. 메시지나 답변 요청을 직접 입력하고 `답변 생성`을 누른다.

개발 중에는 debug 앱의 내부 files 경로에 모델을 ADB run-as로 직접 복사할 수도 있다. 파일명은 `local-reply.litertlm`이다.

## 현재 범위

- 화면에서 입력한 요청만 사용한다. 수집한 대화·내 문장은 아직 모델에 전달하지 않는다.
- API 키, 클라우드 호출, 앱의 인터넷 권한이 없다.
- 입력과 생성 결과는 저장하지 않는다. 화면에서 선택해 복사할 수 있다.
- 최대 입력 1,000자, 전체 문맥 2,048토큰, 출력 최대 192토큰으로 제한한다.
- 생성 시마다 새 대화를 만들어 이전 요청이 다음 답변에 섞이지 않게 한다.
- 취소는 생성 중단을 요청한다. 모델 초기화는 즉시 중단되지 않을 수 있어 끝난 뒤 해제한다.
- 화면을 떠나면 작업을 취소하고 모델 메모리를 해제한다.
- 문맥/출력 한도는 짧은 실험용이며 한국어 품질과 실제 최소 지원 사양은 아직 확정하지 않았다.

## 실기기 확인 항목

- 모델 가져오기·불러오기·답변 생성과 재생성
- 생성 취소 후 다시 생성
- 화면 이동 후 다시 불러오기
- 잘못된 파일·빈 입력의 오류 처리
- 비행기 모드에서도 생성 가능
- 표시된 로딩/생성 시간과 앱 PSS 확인 (최고 메모리 사용량과는 별도)

공식 런타임 가이드: https://developers.google.com/edge/litert-lm/android

## 2026-10-14 실기기 결과

- Samsung SM-S938N, Android API 36, arm64-v8a에서 APK 설치 및 GPU 모델 로딩 성공
- 최초 측정 로딩 4,688ms, 짧은 한국어 초안 생성 503ms, 취소 후 재생성 263ms
- 생성 결과 예: `오늘 좀 미룰까요?` (가상 요청 사용, 실제 대화 사용하지 않음)
- 로딩 후 앱 PSS 약 2,249MB, 생성 후 약 2,318MB
- 화면 종료 후 정리가 완료되면 PSS 약 269MB로 감소
- 생성 취소 후 재생성 성공, 기존 승인 메시지와 말투 문장 개수 유지 확인
- APK 권한 검사에서 INTERNET 권한 없음 확인. 통신 설정을 변경하는 비행기 모드 테스트는 수행하지 않음
- 모델 파일은 SHA-256 검증 후 ADB로 내부 저장소에 배치. 파일 선택기를 통한 2GB 복사 경로는 별도 실사용 검증 필요

위 숫자는 한 기기에서 짧은 요청으로 측정한 값이며 최고 메모리·일반 성능·한국어 개인화 품질을 보장하지 않는다. 배터리 소모와 장시간 반복 추론은 다음 평가 단계에서 측정한다.
