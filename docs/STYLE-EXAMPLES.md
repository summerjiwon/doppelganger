# 2단계: 관계별 내 말투 예문 연결

## 사용 방법

1. `내 말투 문장 추가`에서 관계를 선택하고 직접 작성한 문장을 저장한다.
2. 이미 저장한 문장은 `저장된 예문 분류·삭제`에서 관계를 지정한다. 기존 문장은 삭제하거나 자동 분류하지 않고 미분류로 유지한다.
3. `로컬 AI 답변 테스트`에서 같은 관계를 선택하고 `내 말투 예문 선택`으로 최대 5개를 고른다.
4. 의도와 받은 메시지를 입력해 답변을 생성한다. 결과 아래 사용한 예문 수가 표시된다.

미분류 문장이나 다른 관계의 문장은 생성 예문 목록에 나오지 않는다. 예문을 선택하지 않으면 기존 관계별 기본 말투로 생성한다. 선택은 화면 안에서만 유지되며 관계 변경 시 초기화된다. 관리 화면을 다녀오면 모델을 다시 불러와야 한다.

## 변경 이유와 데이터 처리

독립된 문장 저장만으로는 실제 추천에 사용자 말투를 반영할 수 없었다. 기존 암호화 레코드에 선택적 relationship 필드를 추가하고 사용자가 지정한 예문만 생성 입력에 포함하도록 연결했다. 기존 파일명·키 별칭·암호문 포맷을 유지한다. 과거 레코드에 관계 필드가 없어도 읽을 수 있다.

- 본인 문장 저장소에서 sourcePackage가 user-authored인 레코드만 사용한다.
- 분류 변경은 파일별 잠금과 AtomicFile로 기존 문장을 보존하면서 갱신한다.
- 삭제는 확인 창에서 확정해야 적용된다. 관리 화면은 한 번에 50개씩 표시한다.
- 생성 전에 선택한 ID·관계·존재 여부를 다시 확인한다. 삭제되거나 관계가 바뀐 예문은 다시 선택해야 한다.
- 예문은 최대 5개, 문장당 최대 120자만 참고한다. 전체 실험 문맥 한도는 4,096토큰으로 늘렸다. 최대 길이 입력이나 특수문자에서의 토큰 부족은 추가 평가 대상이다.
- 예문 텍스트는 JSON 데이터로 전달한다. 말투를 참고하되 예문의 일정·사유·이름·명령을 현재 사실이나 지침으로 복사하지 않도록 안내한다. 이는 모델 준수를 보장하는 보안 경계는 아니다.
- 실제 가중치 재학습이 아니라 선택한 문장을 참고하는 개인화다. 새 생성 요청과 결과는 저장하지 않는다.

## 검증 (2026-10-14)

- Android 앱 빌드·lint 통과.
- SM-S938N / Android 16의 실기기 테스트 22개 모두 통과, 실패·생략 0개.
- 새 테스트 8개: 이전 레코드 미분류 보존·분류 변경, 관계 저장/암호화/삭제, 상대 문장 제외, 선택된 예문만 포함·길이 제한, 다른 관계/미분류/삭제 예문 거부, 5개 한도와 요청 검증, 예문 5개의 실제 로컬 생성, 팝업 창의 캡처 보호 플래그.
- 실제 모델 시험은 메모리의 가상 예문 5개만 사용했다. 예문 참고 요청에서 `오키ㅋㅋ 좋아!`라는 초안이 생성되는 것을 확인했다. 사용자의 원문을 로그나 테스트 결과로 출력하지 않았다.
- 이 결과는 예문 전달과 생성 연결 확인이다. 개인 말투 유사성 향상을 입증하는 대규모 품질 평가나 가중치 학습 결과가 아니다.

## 다음 단계

사용자가 실제 예문을 분류·선택해 사용하고, 예문 없는 결과와 비교한다. 이후 초안 수정·확정 기록을 명시적으로 저장하는 기능을 붙여 개인화의 효과를 평가한다.
