# 다음 구현 계획

## 지금 사용자가 할 일

현재 앱에서 다음 두 가지가 유지되면 됩니다.

1. Android 설정에서 Doppelganger의 **알림 접근 권한**을 유지한다.
2. 분석하고 싶은 알림만 앱의 **임시 메시지 검토하기**에서 승인하고, 본인이 쓴 문장은 **내 말투 문장 추가**에서 직접 넣는다.

원하지 않는 대화는 승인하지 않아도 되고, 임시 보관함은 언제든 비울 수 있습니다.

## 다음 개발 순서

### 1. 로컬 말투 프로필 (다음 기능)

- 사용자가 저장한 `내 말투 문장`에서 종결어미, 평균 길이, 이모지, 웃음 표현, 존댓말 비율을 수치화
- 원문 전체가 아닌 작은 프로필로 저장·표시
- 사용자가 프로필을 보고 수정하거나 초기화할 수 있게 제공

완료 조건: 저장한 문장에 따라 “짧고 편한 반말”, “정중한 존댓말” 같은 프로필이 기기 안에서 만들어진다.

### 2. 온디바이스 번역

- 알림/붙여넣기 텍스트에서 언어를 감지
- 필요한 언어 모델만 사용자가 다운로드하도록 안내
- 원문과 번역을 함께 보여 주되, 대화 데이터를 서버에 보내지 않음

완료 조건: 사용자가 요청한 외국어 메시지를 앱에서 오프라인으로 번역할 수 있다.

### 3. 답장 추천 인터페이스

- 사용자가 승인한 대화 또는 직접 붙여넣은 내용만 선택
- 관계(친구·연인·업무), 목표(다정함·거리 두기·명확함), 원하는 길이를 선택
- 로컬 규칙 기반 초안부터 제시하고, 필요할 때만 AI 추천을 요청

완료 조건: 자동 전송 없이 복사 가능한 답장 후보 여러 개를 보여 준다.

### 4. 하이브리드 AI

- 지원 기기에서 온디바이스 생성 AI 가용성 검사
- 로컬 생성 품질이 부족할 때만 클라우드 AI로 전환
- 호출 횟수·입력 길이·사용자별 예산을 제한하고 호출 전 데이터를 미리 보여 줌
- 비밀 키는 Android 앱이 아니라 안전한 중계 서버에 보관

## 나중에 검토할 기능

- 앱 위 번역 오버레이: 별도 권한과 사용자의 명시적 실행이 필요하며, 앱 정책 검토 후 도입
- Windows/iOS: 플랫폼별 개인정보·백그라운드 제약이 달라 Android MVP 검증 후 별도 설계
- 연락처별 관계 메모: 기기 안 암호화와 편집·삭제 UI를 먼저 제공
