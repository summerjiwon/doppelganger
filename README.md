# Doppelganger

> 대화를 맥락과 관계 중심으로 정리하고, 사용자의 말투를 존중하는 답장을 돕는 Android-first AI 코치.

`Doppelganger`는 메신저를 대신 읽거나 답장하지 않습니다. 사용자가 허용한 카카오톡 알림을 기기 안에서 잠시 암호화해 보관하고, 사용자가 **직접 고른 대화와 직접 제공한 내 문장**만 이후 분석 후보로 삼는 것을 출발점으로 합니다.

## 지금 동작하는 것 (Android MVP)

- Android 알림 접근 권한 + 앱 내부 스위치가 모두 켜진 경우에만 카카오톡 알림을 이벤트 기반으로 수집
- Android Keystore의 AES-GCM 키를 사용한 기기 내부 암호화 보관
- OTP·카드 번호·계좌번호 형태의 민감 정보 마스킹 및 중복 알림 제거
- 임시 보관함: 최대 200개, 최대 24시간. 백그라운드 정리 작업은 배터리가 충분할 때만 실행
- 검토 화면에서 사용자가 고른 메시지만 별도 암호화 저장소로 이동
- `내 말투 문장 추가` 화면으로 사용자가 직접 작성한 문장만 말투 학습 후보로 저장

추가 실험 기능: `로컬 AI 답변 테스트`에서 Gemma E2B 모델을 불러와 관계·답변 의도와 선택한 본인 예문을 참고한 초안을 생성합니다. [모델 준비](docs/LOCAL-AI-SETUP.md), [예문 분류·선택 방법](docs/STYLE-EXAMPLES.md)을 참고하세요. 실제 가중치 재학습과 개인화 품질 평가는 아직 수행하지 않았습니다.

아직 하지 않는 것: 서버 전송, 자동 답장, 화면 OCR/접근성 감시, 백그라운드 AI 추론.

## 제품 방향

1. **수집은 최소한으로** — 알림 이벤트만 사용하고, 사용자가 명시적으로 허용·선택한다.
2. **분석은 로컬 우선** — 언어 감지, 번역, 말투 통계는 기기에서 처리한다.
3. **생성은 사용자가 요청할 때만** — 복잡한 관계 분석이 필요할 때만 사용자 승인 데이터를 짧게 요약해 AI로 보낸다.
4. **비용과 배터리를 예측 가능하게** — 자동 클라우드 호출이나 상시 로컬 LLM 실행을 하지 않는다.

자세한 구조와 다음 단계는 [문서](docs/ARCHITECTURE.md), [실행 계획](docs/NEXT-STEPS.md)을 참고하세요.

## 실행

### 웹 프로토타입

```bash
npm install
npm run dev
```

### Android MVP

Android Studio에서 `android/` 폴더를 열거나 아래 명령을 실행합니다. JDK 17 및 Android SDK Platform 35가 필요합니다.

```powershell
cd android
.\gradlew.bat assembleDebug
```

APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 기기에서 알림 접근 권한을 직접 허용한 후에만 수집 스위치를 켤 수 있습니다.

## 개인정보 원칙

- 대화 원문·암호화 저장 파일·API 키·로컬 SDK 경로는 GitHub에 포함하지 않습니다.
- 현재 기본 수집 대상은 카카오톡 패키지(`com.kakao.talk`)입니다.
- Android 앱 ID는 설치본과 로컬 데이터를 보존하기 위해 당분간 `com.sync.coach`를 유지합니다. 사용자 표시는 Doppelganger입니다.

## 상태

현재 버전은 **0.1.0 MVP**입니다. 실제 기기에서 수집·승인 저장과 관계·본인 예문 기반 로컬 생성을 확인했습니다. 다음 목표는 수정·확정 기록과 개인화 품질 평가입니다.
